# Steve Musili Portfolio

A personal portfolio web page that describes my background, skills, projects I have done, and contact information.

## Live Demo Link

[View my portfolio on GitHub pages](https://stevemusili.github.io/stevemusili-portfolio/)

## Features 

- Home section with a short introduction
- About Me section with a short bio and avatar
- Skills section rendered on the page using JavaScript
- Projects section rendered on the page using JavaScript
- Project cards displays project title, description, and technologies used
- Contact section with email and GitHub link
- Hover effects on buttons, images, links, and project cards
- Dark and Orangered-themed design

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run the Project Locally

1. Clone the repository

```
git clone https://github.com/stevemusili/stevemusili-portfolio.git

```

2. Open the project folder.

```
cd stevemusili-portfolio

```

3. Open 'index.html' in your browser.

## What I Learned

Through this project, I have learned how to structure a portfolio webpage using HTML and style it using CSS. I also learned how to use JavaScript arrays, objects and loops to insert skills and project cards on the webpage.
